# 🧮 CodeAlpha Calculator V2

A responsive calculator built using HTML, CSS and JavaScript.

## 🚀 Features
- Addition
- Subtraction
- Multiplication
- Division
- Percentage (%)
- AC (All Clear)
- DEL (Delete)
- Responsive Design

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
